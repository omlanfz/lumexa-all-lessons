# Activities — Lesson 4: Building an AI Rock-Paper-Scissors Game

## Activity 1: Play the Game (10 min)
1. Open project.sb3, click the green flag.
2. Play 5 rounds using keys 1/2/3. Record your Score after each round.

## Activity 2: Explore the Code (15 min)
1. Click on the Referee sprite.
2. Find the block that picks the computer's move randomly.
3. Find the if/else-if chain and trace one full round through it out loud with a partner.

## Activity 3: Remix It (15 min)
Choose ONE:
- Change the winning sound or message.
- Add a new backdrop.
- Add a "Best of 5" counter variable that ends the game after 5 rounds.

## Activity 4: Plan the AI Upgrade (10 min)
Read the first page of `AI_Training_Guide.md`. Write 3 steps you would need to do to add real gesture recognition later.
