# Course 11 — Python for Young Builders

**Ages 6–11 · 8 Lessons · 3 Portfolio Projects**

The bridge from visual to text-based coding. Your child writes their first Python programs — variables, loops, and their very own mini projects. Taught slowly, with patience, and lots of fun.

## Why It Matters

Moving from visual blocks to typed code is a big milestone. This course makes that jump gently, showing students that the logic they already know from Scratch works exactly the same way in real, professional code.

## Lesson Breakdown

1. From Scratch blocks to Python text
2. Variables and user input
3. Printing and string formatting
4. If/else decisions
5. While loops and for loops
6. Lists and simple data
7. Building a mini quiz app
8. Final project: our own mini game

## Portfolio Projects

1. **Personal Quiz App** (`personal_quiz_app.py`) — asks the player's name and several real questions, tracks score with a variable, gives a friendly tiered final message.
2. **Simple Calculator** (`simple_calculator.py`) — real +, −, ×, ÷ calculations, friendly division-by-zero handling, loops for repeated use.
3. **Word Guessing Game** (`word_guessing_game.py`) — a real `random`-module + list-based guessing game with limited attempts and win/lose messages.

Every project is a real, runnable `.py` file — each was actually executed with simulated input to confirm it works, and the real transcript is in its README.
