# 🚀 Lesson 1 Activities: My First Python Program

## Activity 1: Say Hello to the World

**Goal:** Write and run your very first Python program.

**Steps:**
1. Open Thonny.
2. Click in the editor (top box).
3. Type: `print("Hello, world!")`
4. Press the green Run button.
5. Check the shell (bottom box) — do you see your message?
6. Raise your hand and show a teacher your first successful run!

---

## Activity 2: Introduce Yourself in Code

**Goal:** Practice writing multiple `print()` lines.

**Steps:**
1. In a new line under your first `print()`, add a second one with your name, like:
   ```python
   print("My name is Alex!")
   ```
2. Add a third line that tells us your favorite color:
   ```python
   print("My favorite color is green.")
   ```
3. Add a fourth line telling us your favorite animal:
   ```python
   print("My favorite animal is a panda.")
   ```
4. Run the whole program. You should see 4 lines of output.
5. Compare your output with a partner's — whose favorite animal is different?

---

## Activity 3: Compare Scratch and Python

**Goal:** See how a Scratch script and Python code do the same job.

**Steps:**
1. Look at a Scratch project with a sprite that has this script:
   - When green flag clicked → say "Hello!" for 2 seconds.
2. On paper or in Thonny as a comment, write what the Python version would look like:
   ```python
   print("Hello!")
   ```
3. Discuss with a partner: what's the same? What's different? (Same: it makes words appear. Different: one uses blocks, one uses typed text.)

---

## Activity 4: Break It and Fix It

**Goal:** Practice recognizing and fixing simple errors.

**Steps:**
1. Type this program into Thonny:
   ```python
   print("I love coding!"
   ```
2. Run it. You should see a red error message.
3. Look carefully — what's missing? (a closing parenthesis)
4. Fix it so it becomes:
   ```python
   print("I love coding!")
   ```
5. Run it again — the error should be gone and your message should print.

---

## Activity 5: Rocket Picture Drawing (Extension)

**Goal:** Use several `print()` statements to create a picture.

**Steps:**
1. Type each line of the rocket, one `print()` per line:
   ```python
   print("   /\\   ")
   print("  /  \\  ")
   print(" |    | ")
   print(" |PYTHON|")
   print("/______\\")
   ```
2. Run it and see your rocket appear in the shell.
3. Try changing symbols to design your own picture — a star, a house, or a robot face!
