# 🚀 Lesson 1: From Blocks to Words — Hello, Python!

## 👋 Welcome, Young Builder!

Remember in Scratch, when you clicked the green flag and your sprite said **"Hello!"**? You built that by snapping together colorful blocks.

Today you're going to learn something amazing: computers can understand **typed words** too! This is called **Python** — it's a real programming language used by grown-up coders all over the world, and now YOU get to use it.

---

## 🧠 Think Like a Coder

> A Scratch "say" block and a Python `print()` command do the **exact same job** — they both make words show up. The only difference is *how* we tell the computer to do it: blocks vs. typed text.

---

## 💻 Step 1: Open Thonny

1. Open the **Thonny** app (or your Repl.it project).
2. You'll see two boxes:
   - The **top box** (editor) is where you type your code.
   - The **bottom box** (shell) is where your messages appear.

## 💻 Step 2: Type Your First Line of Code

Click in the editor and type this exactly:

```python
print("Hello, world!")
```

## ▶️ Step 3: Run It!

Press the green **Run** button (or the F5 key). Look at the bottom box — you should see:

```
Hello, world!
```

🎉 You just wrote and ran your first Python program!

---

## 🤖 Robot Tip

Python is very exact. It needs:
- **Quotes** `" "` around any words you want it to show.
- **Parentheses** `( )` around what goes inside `print`.

Miss one, and Python gets confused!

---

## 💻 Step 4: Add More Lines

Try typing this whole program:

```python
print("Hello, world!")
print("My name is Python, and I love to help you build things!")
```

Run it and watch both lines appear in the shell.


Run it and see your own greeting appear!

---

## 🔍 Debug Detective

Uh-oh! This code has a bug in it. Can you find what's wrong?

```python
print("Hello, world!)
```

**Hint:** count the quote marks. 🕵️

**The Fix:**
```python
print("Hello, world!")
```
There was a missing closing quote `"` before the closing parenthesis. Python needs a quote at the **start** and the **end** of your text.
