## ⭐ Bonus Challenge: Math With Boxes

Variables can hold numbers, and Python can add them together! Try this:

```python
score = 10
bonus = 5
total = score + bonus
print(total)
```

Can you make a variable called `penalty` and subtract it from `total`?

```python
penalty = 3
final_score = total - penalty
print(final_score)
```
