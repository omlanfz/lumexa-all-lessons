# Lesson 4 Challenges

## 🎯 Mini Challenge
Add a second key-press event to your sprite (try the up arrow key) that does something different than your first key event. Test both keys and make sure they each do their own thing.

## ⭐ Bonus Challenge
Build a three-sprite broadcast relay: Sprite A broadcasts "scene 2," Sprite B receives it, reacts, and broadcasts "scene 3," and Sprite C receives that and reacts too. Watch the message travel like a note passed down a row of friends!

## 🏠 Take-Home Challenge
Think about how passing a note in class works: one person writes it and passes it along (like a broadcast), and the next person reads it and reacts (like "when I receive"). Come up with your own silly broadcast message idea (like "surprise!" or "dance time!") that you'd love to use in a Scratch project soon.
