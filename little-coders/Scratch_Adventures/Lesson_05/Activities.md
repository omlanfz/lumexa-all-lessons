# Lesson 5 Activities

## Activity 1: Build a Square Without Loops (then WITH loops)

1. First, try stacking FOUR separate "move 50 steps" and "turn right 90 degrees" pairs (8 blocks total) to make a square. Notice how many blocks that takes!
2. Now delete those and build: "repeat [4]" with just ONE "move 50 steps" and ONE "turn right 90 degrees" inside it.
3. Run both versions — same square, way fewer blocks the second time!

## Activity 2: Forever Animation

1. Add "when green flag clicked."
2. Add a "forever" block.
3. Inside it, put "next costume" and "wait [0.3] seconds."
4. Click the green flag — your sprite animates non-stop!
5. Click the red stop sign (top right) to stop it.

## Activity 3: Loopy Dance

1. Add a "repeat [8]" block.
2. Inside it: a move block, a turn block, and a "next costume" block.
3. Add a "play sound until done" block inside the loop for rhythm.
4. Click it and enjoy your sprite's dance!

## Activity 4: Shape Explorer

1. Take your square script from Activity 1.
2. Change the repeat count to 3, and change the turn angle to 120 degrees. What shape do you get?
3. Try repeat 6 with a turn angle of 60 degrees. What shape now?
4. Talk with a partner: what's the pattern between the number of sides and the turn angle? (Hint: 360 ÷ number of sides!)
