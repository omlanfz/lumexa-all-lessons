# Lumexa Digital Independence Path — Complete Package (All 3 Courses)

**Ages 15–18 · 3 courses · 24 lessons.** This is the complete Digital Independence Path:
**Course 16 — Build Your Professional Identity**, **Course 17 — Skills That Pay**, and
**Course 18 — Professional Presence & Opportunity Building**, all fully built (all 24
lessons, coding project, the full Client Simulation package, worksheets, PDFs).

## How to Teach This
Start with each course's `Course_Teacher_Guide.md` (or its PDF), then work lesson by lesson —
each lesson folder has everything needed for that one class: an Instructor Guide (PDF, for
you), a Student Lesson (PDF, share via screen or send to students), and a Worksheet (PDF,
printable or fillable). Course 17, Lesson 8 additionally needs its `Simulation_Resources/`
folder — read the Instructor Guide first, since you'll role-play the fictional client across
three sessions.

## The Non-Negotiable Safety Rules (apply throughout all 3 courses)
- Never instructs bypassing an age requirement or misrepresenting age, for any platform.
- A written agreement/template used in class is explicitly labeled non-binding — never taught
  as a real legal contract.
- LinkedIn's 16+ age requirement (subject to local law) is stated plainly in Course 18;
  students below the applicable age use the equally credible portfolio-first alternative.
- Real paid client work as a minor is framed as needing parent/guardian awareness.
- All platform age/account rules are flagged as subject to change and should be verified
  against current policy before teaching.
