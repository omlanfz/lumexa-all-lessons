# Course 16 — Final Portfolio Assessment Rubric

| Criterion | Beginner (1) | Developing (2) | Proficient (3) |
|---|---|---|---|
| Site structure | Missing sections or broken layout | All 5 sections present, minor layout issues | All 5 sections present, responsive, no console errors |
| Bio | Generic or missing | Present but generic/corporate-sounding | Honest, specific, matches the bio formula |
| Case studies (2–3) | Fewer than 2, or vague | 2–3 present but thin on detail | 2–3 present, each follows Problem/Approach/Result/Learned format |
| Brand consistency | No consistent palette/type | Some elements applied inconsistently | Palette + type + tone consistently applied site-wide |
| Deployment | Not live | Live but broken links/errors | Live, working URL, tested on phone and laptop |
| Integrity | Contains fabricated claims or testimonials | Mostly honest with minor exaggeration | Fully honest — every claim is backed by real, checkable evidence |

**Scoring:** 6–9 = Beginner · 10–14 = Developing · 15–18 = Proficient
