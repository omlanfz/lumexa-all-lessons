- **My Approach:** Built a simple form, fetched forecast data, mapped conditions to a small set of activity suggestions, styled it to feel calm and simple.
- **Result:** A working single-page tool that updates suggestions live based on real weather data.
- **What I Learned:** How to work with an external API and handle cases when data doesn't load.
